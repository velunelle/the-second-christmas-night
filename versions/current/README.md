# 第十二个圣诞夜

在线版本：https://snowfall-nocturne-velunelle.fuzzy-egret-1442.chatgpt.site/

## 文件怎么用

- `第十二个圣诞夜_独立版.html`：引擎、代码、模型、纹理、字体和开场都已打包进一个 HTML。无需 CDN；用支持 WebGL 2 的浏览器打开。手机文件管理器的预览窗口可能不提供三维图形，请选择浏览器打开。
- `dist/index.html`：多文件网站入口。请保留整个 dist 文件夹。进入项目目录运行 `python3 dist/serve.py`，浏览器打开 `http://localhost:5179`。手机和电脑在同一网络时，可通过电脑的局域网 IP 和 5179 端口访问。
- `第十二个圣诞夜_源码汇总.txt`：按路径排列的可编辑文本源码。模型、纹理、音频等二进制文件在完整 ZIP 的 dist/assets 中。
- `第十二个圣诞夜_完整源码.zip`：完整网站源文件，以及 portable 文件夹中的独立 HTML、源码文本和本说明。保留这一份 ZIP 即包含全部交付格式。

## 本轮修改

所有界面、招牌及开场统一为本地圆润字体（站酷快乐体，附 OFL 许可证）。删除原唱播放器和外部视频界面；保留背景音乐及本地音频导入。导入的个人音频保存在当前浏览器，不随源码包分发。

移除全部车辆、后排与填充高楼，减少部分非商铺临街楼、连桥、路障和花箱；保留全部商铺。实际街区现有 40 个建筑地块。行人改为一批半透明冬装剪影，雨天使用伞影。圣诞树完整几何和材质保留。

雨夜固定为中等雨量：雨域围绕视角对称分布，固定下落速度，不再按周围灯光强弱改变可见度。室内与实体屋檐仍遮雨。

宣传片为 58 秒、六个场景。缩短穿行路线与重复环绕，稍慢运镜；保留诗句、十二声钟声和结尾烟花。烟花扩散放大约 1.8 倍。楼宇窗口合并为更宽的玻璃模块，增加大幅立面屏幕的占比。

默认渲染像素比仍为 3 倍，可手动调到 8 倍；完整反射和 8192 阴影设置保留。本轮通过减少场景负担改善性能，不自动下调清晰度。

## 操作与兼容性

横屏使用：左侧摇杆移动，右侧滑动环顾；一键电影漫游可直接录制。文案编辑器支持修改并导入、导出 JSON。离线文件和在线站点各自使用自己的浏览器存储；转移文案请导出 JSON。音频播放、全屏和录制需要点击操作，并取决于浏览器支持。iOS 文件预览器若阻止本地 HTML，请使用多文件本地服务器或在线版本。

打包 HTML 改变资源交付方式，不会替代 WebGL，也不会单独提高三维渲染帧率。高像素比、全分辨率反射及大阴影依然需要较强 GPU。

已检查源码语法、离线资源打包、40 个建筑地块、零车辆、剪影矩阵、均匀雨参数、58 秒镜头及十二次钟声事件。当前远程浏览器禁用了 WebGL，无法在此确认实际画面效果或手机帧率。

## 源码与许可

`dist/src/` 为主要应用源码，`dist/opening/` 为开场源码，`dist/vendor/` 为随包依赖，`dist/licenses/`、`dist/fonts/OFL.txt` 及原目录中保留的许可证为第三方许可。请保留鸣谢与许可文件。

基础夜城：Hyraland/night-rain-city-skill；开场参考：knacl47/between-us；松树：dgreenheck/ez-tree；烟花：toddegray/fireworks。具体许可见包内文件。引擎版本 three.js 0.169.0。

`scripts/build-standalone.py` 可重新生成独立 HTML，需要 Python 3 与官方 esbuild CLI。网站本身无需构建即可通过静态服务器运行。
